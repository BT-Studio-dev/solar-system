Texture Pack
============

Every sub folder with a pack.ini is a recolour pack. Pick one in the Library
tab; the scene tints the lit side of every body by "strength" percent.

    name     = Warm Dusk      listing name (default: folder name)
    note     = amber light    one line under the name
    tint     = #ffb066        target colour
    strength = 35             0-100, how far colours move to the tint

Set the pack back to "Theme colours" to return to the palette of the active
colour theme (F3).
